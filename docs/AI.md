# たびまる（AIの読み取り）の設定

たびまるは、文章（またはレシートの写真）から、支出を読み取ります（複数件も）。入力欄は1つで、かんたんな文は、AIなしで、そのまま記録されます。記録で読めない文（払った人・割る人・複数の支出）と、レシートの写真だけ、たびまるが読み取ります。キャラクターは、アプリのアイコンと同じ、チケットです。

## いまの使い方（無料）
**Cloudflare の無料のAI（Workers AI）** を使います（`wrangler.jsonc` の `ai` の設定）。APIキーも、新しい契約も、要りません。**公開すると、ログインした人には、ボタンが出ます。**
- 無料枠は、Cloudflare のアカウント全体で、1日分です。使い切らないように、**全体で1日100回**までにしています（`AI_DAILY_TOTAL`）。届いた日は、「たびまるは、今日は…おやすみです」と出て、明日また使えます。Free プランでは、枠を超えても、請求されません（Workers Paid プランの場合は、超えた分が請求されます。プランを確認してください）。
- 使うモデル: 文章は `@cf/meta/llama-3.3-70b-instruct-fp8-fast`（だめなら `@cf/meta/llama-3.1-8b-instruct`）、写真は `@cf/meta/llama-3.2-11b-vision-instruct`。アカウントで使えないモデルは、次のモデルに、自動で切り替わります。変数 `AI_WORKERS_MODEL`（文章）・`AI_WORKERS_VISION_MODEL`（写真）で、先に試すモデルを変えられます。
- **止めたいとき**: Cloudflare の変数に `AI_OFF` = `1` を足すと、すぐ止まります（ボタンが消えます）。
- 写真には、見本の値を入れない専用の指示文を使います（見本の値を、そのまま返す不具合があったため）。
- 精度は、公開して、試すまで、わかりません（日本語の口語、レシートの写真）。

## 有料のAI（Anthropic）に切り替えるとき（任意）
`ANTHROPIC_API_KEY` を入れると、Cloudflare のAIではなく、Anthropic を使います（精度は上がる見込み。**有料**）。**プライバシーポリシーに、Anthropic の項目を足し直す必要があります。**

### 1. Anthropic の APIキーをつくる
1. https://console.anthropic.com/ にログインします。
2. **API Keys** で、キーをつくって、コピーします（チャットには貼らない）。
3. **Billing（請求）→ Limits（上限）** で、**月の使用上限（金額）** を決めます。これが、費用の最後の守りです。

### 2. Cloudflare に登録する
Cloudflare → Workers & Pages → `tabiwari` → 設定 → 変数とシークレット → 追加。
- 種類：**シークレット**、名前：`ANTHROPIC_API_KEY`、値：コピーしたキー。
- 保存して、デプロイします。

## 回数の制限（変えたいとき）
通常の「変数」（シークレットではない）で、次を足すと、変えられます。
- `AI_DAILY_LIMIT`：1人1日の回数（初期値 5）
- `AI_MONTHLY_LIMIT`：全体の月の回数（初期値 2000）。届くと、その月は、たびまるが休みになります。
- `AI_DAILY_TOTAL`：Cloudflare のAIのとき、全体の1日の回数（初期値 100）
- `AI_MODEL`：Anthropic のとき、使うモデル（初期値 `claude-haiku-5-5`）

## しくみ
- ログインした人だけ。サーバー（`worker/ai.js`）が、AIを呼びます。APIキーは、サーバーの中だけです。
- AIの答えは、サーバーで検査します（金額、名前がメンバーにあるか、指定の合計、など）。おかしいものは、はじきます。
- アプリは、答えを**確認の画面**に出します。［記録する］を押すまで、何も記録しません。
- 写真は、端末で小さく（長い辺 1280px）してから送ります。サーバーには、保存しません。
- AIにつながらなかったとき・失敗したときは、回数を、減らしません。
- テスト: `test/ai.api.test.mjs`（疑似のAIサーバー `test/fake-ai.mjs`。本物のAIには、つながない）、`test/ui.e2e.mjs`。
