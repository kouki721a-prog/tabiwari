# Tabiflow デザイン仕様（全画面）

2026-11-26 作成・同日 v197 に更新。**v197 時点の、実際の画面**（`docs/design/*.jpg`。390×844・テスト用の試用データ）と、その決まり・次の案をまとめたもの。
見た目の決まりの原本は `HANDOFF.md` の「UIのルール」。ここは、画面ごとに「何が、どこに、なぜ」を書く。

## 1. 世界観と部品

**旅の切符**。紙（`--cream`）・点線（`--dash`）・切り欠き（ページの背景色の円）・判子（丸）・駅（点線の路線の点）で、すべての画面を組む。

| 部品 | 決まり | 使っている所 |
|---|---|---|
| 切符（紺） | 旅のカラー（`--navy`）の面。左右の切り欠き。大きな数字は tabular-nums。 | 予算・積立の切符 |
| 小さな切符（クリーム） | `--cream` の紙・角丸14px・**左に旅の色の縁**（4px）。点線と切り欠きで、受け取り方の行と区切る。 | 精算の送金（v191）・積立の人ごとの行（v192）。ホームの旅行カードも、クリーム色の切符（右に半券） |
| 判子 | 丸＋**線画の絵**（海＝波・山・夕焼け・桜・雪。v184）。スタンプは黄色の丸＋漢字1字。 | 旅のカラー・ホームの旅行名・スタンプ |
| 路線 | 点線に駅。通った所は黄色の実線、今日は大きく光の輪。 | 記録タブ（日ごと・v187）・積立の切符（25%ごと）・最初のページ |
| 見出し | 小さな見出しは等幅（`--mono`）。日の見出しは「11/26(木) 2日目」。 | 日付・設定の見出し |
| 押せるもの | **44px 以上**（v181・v188）。 | すべて |
| 色 | アクセントは**黄色だけ**（LINEログインだけ公式の緑）。旅のカラーは切符の色だけを変える。 | — |
| 動き | 0.2〜1.2秒。「動きを減らす」では止める。途中の状態はメモリに持つ。 | — |
| 暗い画面 | `--paper`/`--card`/`--ink` を暗い値に。切符の色は、旅のカラーのまま。 | 全画面（`20〜23-dark-*.jpg`） |

文言は、やわらかいですます調。「ふたり」（メンバーがちょうど2人）。「成功しました」「！」は使わない。

## 2. 画面ごとの仕様

### 2-1. 最初のページ（旅行が0件）  `01-first.jpg` `01b-first-scrolled.jpg`
- **役割**: はじめての人に、アプリの価値を、読み物で伝える。この画面だけ、縦に長くてよい。
- **v206 で足した部分**: 「割り勘の、明細」の前に、**「記録するたびに、旅が進む」**（今日のミッション・旅の道のりの、実際の画面の写真つき＝`icons/lp/mission.png`・`quest.png`。たびまるの成長と、切符の発券の一文）。よくある質問に「道のりやたびまるの成長は、友だちにも見えますか？」。
- **構成**: 上の行（Tabiflow・LINEでログイン・歯車）→ 見出し「「いくら出したっけ」を、なくします。」→ 招待された方の入口 → サンプルの切符（初の判子）→ 路線図の場面（積立・旅先・精算…）→ 明細・お知らせ・はじめ方・質問。
- **固定**: ［旅行をつくる］は、画面の下に固定（安全領域つき・v179・余白の2重取りを直した v186）。
- **動き**: 開いたとき、切符が上がり、判子が押され、スクロールで路線が伸びる。1回だけ。
- **次の案**: LINEログインの価値（通知が届く）を、最初の画面で、1行で伝える。

### 2-2. 旅行をつくる  `02-new.jpg`
- **役割**: 名前・日付・予算・自分の名前の4つだけで、旅行を作る。
- **構成**: 戻る＋題 → 入力欄（名前・出発日・帰着日・予算＋よく使う金額のチップ・自分の名前）→ 下に固定の［この内容でつくる］。入力欄に、自動でキーボードを開かない。
- **ミッションのピル（v202）**: 路線の右に、2つの小さな丸い札（44px）。**炎＋連続日数**（今日の記録があると、炎が点く）と、**✓＋今日のミッション n/3**（ぜんぶで緑）。押すと、「今日のミッション」のシートが開く。
- **発券（v200）**: 「この内容でつくる」を押すと、旅行の画面の上に、切符がスロットから印字されて出てきて（0.8秒）、「初」の判子が押され、紙吹雪（約1秒）。全体で約2.3秒。**押せるものはふさがない**（タップは、そのまま通る）。「動きを減らす」では出ない。
- **ライブ切符（v194）**: 上に、サンプルと同じ紙の切符（行き先・日程と泊数・予算）。打つたびに入り、名前が付いた瞬間に「初」の判子が一度だけ押される。**3つの欄は押せる**（押すと、その入力欄に移り、押した欄に黄色の下線。v198）。**画面の高さが720px以上のときだけ**出る（フォームが1画面に収まる決まりのため）。何も保存しない。

### 2-2b. 招待された人の画面（参加のシート）（v207）
- **役割**: 招待のリンクから来た人（最初に開く人の、大半）が、参加する。精算のお知らせを、LINEで受け取る最初の機会。
- **構成**: 「◯◯」に招待されました → 旅行のカード → （LINEログインが使えて、まだログインしていないとき）**緑の公式ボタン「LINEでログインして参加」**と、良い点3つ（精算のお知らせがLINEに届く・名前はLINEの名前が入る・端末を替えても戻せる）→ 「または、ログインせずに」→ 名前の欄 →（すでに参加している人の選択）→ 参加のしかた → ［名前だけで参加する］。
- **ログイン済みのとき**: ログインの欄は出ない。名前に、LINEの名前が入っている（「変えられます」の一言）。ボタンは［参加する］。
- **ログインで、いったん離れても**: 招待を30分覚えておき、ログインが終わると、参加の画面を開き直す（ページが開いたままなら、名前を埋めるだけ）。
- **名前は変わらない**: 先に名前で参加して、あとからLINEでログインしても、名前は、そのまま。お知らせが、届くようになるだけ。
- 「LINEのログインは、要りません」とは書かない（このアプリの強みを打ち消すため）。

### 2-3. ホーム（旅行の一覧）  `03-home.jpg` `17-home-ended-tab.jpg`
- **役割**: 旅行を選ぶ。いまの段階（準備中・旅行中・終了）が、ひと目で分かる。
- **構成**: Tabiflow＋歯車 → タブ（これから・旅行中／終了した旅行）→ 旅行カード（判子・名前・段階・日付・「今日の目安」または「あと◯日で出発」・メンバー・バー・右の半券に残りの金額）→ ［同じメンバーで次の旅行をつくる］→ ［共有リンクで参加する］→ ［旅行をつくる］（固定）。
- **段階ごとの顔**: 旅行中＝黄色の枠・今日の目安。準備中＝積立の額。終了＝「精算があと◯件」。
- **開く瞬間（v199）**: アプリを開いたとき・ホームに戻ったとき・タブを切り替えたとき、カードが1枚ずつ右から滑り込み（0.46秒・0.14秒ずつ）、旅行名の判子が押され、旅行中の路線が今日の駅まで灯り、「あと20日で出発」が0から数えて出る。全体で約1.2秒。30秒以上アプリを離れて戻ったときも、もう一度。「動きを減らす」では動かない。
- **路線（v195）**: 旅行中のカードの、顔の右に、記録タブと同じ日ごとの路線を小さく（「2日目」）。メンバー5人以上・11日以上の旅では、場所が無いので出さない。

### 2-4. 記録タブ  `04-record.jpg`
- **役割**: 旅先で、毎日開く画面。1件の記録が、最短で終わる。
- **構成（上から）**: 予算の切符（今日の目安）→ **旅の路線**（2日目 / 3日・v187）→ ひとこと入力＋［記録］→ チップ（44px）→ 日の見出し（日付・◯日目・**スタンプ 5/10**・その日の合計）→ 支出の行（押すと直す・左スワイプで削除）。
- **一度に1つだけ**: 説明は、最初の記録まで（「夕食 2000円のように書いて…」）。スワイプの説明は、3件目から1回だけ。
- **下**: ナビ（積立・記録・精算・設定）＋中央の［＋］。
- **次の案**: 今日の合計の上に、**日ごとの小さな棒**（旅の間の使い方が、見える）。

### 2-5. 支出を記録（シート）  `05-add-sheet.jpg`
- **役割**: 金額が主役。ほかは、なくてもよい。
- **構成**: 大きな金額の枠（どこを押しても入力）→「1人あたり」の説明 → 内容・日付 → カテゴリ（6つ・判子つき）→ 誰が払った？（**44px**）→ 誰の分？（全員・個別）→ ［割合・金額を変える］→ ［記録する］（固定）。
- **カテゴリのタイル**: 6つとも線画の絵（交通＝電車・宿泊＝ベッド・食事＝フォークとナイフ・観光＝カメラ・お土産＝ギフト・その他＝三つの点。v204）。支出の行の左のタイルも、同じ絵。色は、カテゴリごとのまま。
- **安全装置**: 10億円超は保存できない。予算を超える／予算の半分以上は、1回だけ確認（v181）。
- **次の案**: 金額を打つと、「1人あたり 4,000円」が、金額の枠の下に、その場で出る（いまは説明の行）。

### 2-6. 積立タブ  `07-save.jpg` `15-upcoming-save.jpg` `08-save-sheet.jpg`
- **役割**: 旅行の前に、ひとりずつ、貯める。
- **構成**: 積立の切符（みんなの積立・25%ごとの駅・目標に対する%）→ めやすのカード（毎週◯曜日に約◯円・［◯円を積み立てる］）→ 人ごとの**小さな切符**（バー＋25%の目盛り・［積み立てる］44px・v192）→ 積立の記録（1件でもあれば。押すと直す）。
- **一度に1つだけ**: 記録が無い間は、説明が1つ（「…押すと、直したり、消したりできます。」）。記録の一覧は、出さない（v189）。
- **次の案**: 目標に届いた人の行に、「積」のスタンプを、切符の縁に押す。

### 2-7. 精算タブ  `06-settle.jpg` `16-ended-settle.jpg`
- **役割**: 旅行のあと、誰が誰にいくら送るかを、迷わず、通知つきで終える。
- **構成**: 予算の残り → 第1回の精算（あと◯件・残り◯円）→ 受け取り方・共有の2行（点線の枠だけ・v191）→ 送金の**小さな切符**（誰→誰・金額・［済み］44px。受け取る人が複数なら「◯◯さんへ 合計」の見出し）→ ［この精算を確定する］→ ひとりずつの内訳（立て替え・負担・差額）→ 精算の履歴。
- **済み**: 切符が、うっすら緑になり、［済み］が緑の塗りに。
- **お祝い（v200）**: 積立が目標に届いたとき・みんなの精算が済んだときの大きな判子（「積立が目標に届きました」「みんなの精算が済みました」）で、紙吹雪が舞う。
- **確定の演出**: 押した瞬間に、予算の切符の半券が切り取られて飛び（v152）、大きな「精」の判子が押される。さらに、送金の切符が、1枚ずつ持ち上がって、右へ滑っていく（v196。履歴へ移るため。「動きを減らす」では出ない）。

### 2-8. 旅行の設定（シート）  `09-trip-settings.jpg`
- **構成**: 名前・出発日・帰着日・予算 → メンバー（名前の枠）→ 友だちと共有（点線の枠）→ CSV書き出し・取り込み・まとめ画像 → ［この旅行を削除］（赤）→ ［保存する］（固定）。
- **次の案**: 共有の枠に、LINEで友だちに送るボタンを、緑（公式）で。

### 2-9. 旅のカラー（シート）  `10-theme.jpg`
- **構成**: 5つのタイル（判子の絵＋名前）・選んだ1つは黄色の枠・［自動にもどす］・［とじる］。色は、この端末だけ。

### 2-10. 旅の道のり・スタンプ（シート）  `11-stamps.jpg`（v201 で、道のりが加わった）
- **入口**: 記録タブの日の見出しの中の「スタンプ 5/10」（→ 道のり）と、路線の右のピル（→ ミッション）。シートには、**ミッション・道のり・スタンプ**の3つのタブ（44px）。
- **道のり（旅のクエスト）**: 積立→旅→精算の道のりを、地図にしたもの。**旅行のデータから、毎回算出**（新しい保存なし。共有している旅行は、全員が、同じ進み具合を見る）。
  - 上: 完成度のリング（0からぐるっと描かれ、数字が数えて出る）＋「みんなで、ここまで来ました」「あと◯個で、金の判子」。
  - **次の目標**（NEXT）: いまの章の、最初の未達成の目標と、**そこへ連れていくボタン**（積み立てる→積立のシート／記録する→支出のシート／精算へ→精算タブ）。
  - **3つの章**: ① 出発の前（積立が25・50・75%・目標に届く）② 旅のあいだ（はじめの記録・みんなで割り勘・食/交/宿/遊/土を集める・全部の日に記録する）③ 帰ってから（精算を確定・みんなの精算が済む）。章の状態: いま（黄色の縁）・クリア（緑の縁・点線が黄色の実線に）・これから。各目標は判子（達成＝黄色／まだ＝点線）。**行を押すと、説明と［ボタン］が開く**。
  - 一番下: **金の判子**（ぜんぶ達成で手に入る。10個のスタンプには数えない）。旅のまとめ画像（レシート）にも、「旅の完成度 ◯%」と金の判子が載る。
- **お祝い**: 章をクリアしたとき・金の判子を手に入れたとき、大きな判子＋紙吹雪（一度だけ。この端末で覚える。スタンプと同時のときは、スタンプのあと）。
- **炎の絵（v209）**: BeReal の炎のように、**丸いしずくの形の炎の中に、小さな炎**。先が赤・まんなかが橙・下が黄色のグラデーション。今日の記録がまだのときは、同じ形の灰色。明るい画面・暗い画面の両方で、同じ絵（色は CSS の `stop-color` で切り替える）。ミッションのシートの大きな炎は、ふくらみの中心に連続日数が入り、光る。路線のピル・上のバナーも、同じ炎。
- **ミッション（v202）**: 旅行中の毎日。**連続記録**（炎・「3日連続」・最長・記録のある日 n/m・日ごとの丸。今日の記録が無い日は途切れない＝「今日の記録で、4日連続につながります」）と、**今日のミッション3つ**: ①今日の1件を記録する ②今日の目安のなかにおさめる（超えたら、赤ではなく「また明日」・棒は灰色）③新しいカテゴリを1つ記録する（五つそろっていれば、自動で達成）。未達成には［記録する］。**「毎日記録」メダル**（道のりの目標のひとつ）の進み具合。旅行の前・後は、説明だけ。**お祝い**: ミッションがひとつ進むと、上から小さなバナー（炎＋「ミッション達成：…（2/3）」）。3つそろうと、大きな判子＋紙吹雪＋「◯日連続です」。一度だけ（この端末で覚える）。
- **スタンプ**: 10個の判子。**カテゴリの5つ（食・交・宿・遊・土）は、線画の絵**（フォークとナイフ・電車・ベッド・カメラ・ギフト。v203）。ほかの5つ（初・割・積・精・済）は、これまでどおり漢字。絵は、スタンプの格子・日の見出しの小さなスタンプ・道のりのカテゴリの行・ミッション・押した瞬間の大きな判子・旅のまとめ画像（レシート）で、同じものが出る。（押した日つき）。押していないものは、点線の丸。

### 2-11. たびまる（シート）  `12-tabimaru.jpg`
- **成長（v205）**: スタンプ1個＝1ポイント、金の判子＝+5ポイント（この端末の全部の旅行から、毎回算出。保存なし）。**5つの姿**: Lv.1 たびまる（0）・Lv.2 旅人たびまる＝帽子（5）・Lv.3 旗持ちたびまる＝旗（15）・Lv.4 車掌たびまる＝車掌の帽子と笛（30）・Lv.5 駅長たびまる＝金の帯とキラキラ（50）。**入口**: ホームの歯車の左のたびまる（Lv のチップつき・44px）と、旅行の画面のたびまるのシートの下の行。**シート**: 大きなたびまる・「次の進化まで、あと◯ポイント」の棒・持ち物5つ（帽子・旗・笛・駅長の帽子・金の判子。まだのものは「？」）・ポイントの貯め方。進化したとき、たびまるの絵つきの大きな判子＋紙吹雪（一度だけ。この端末で覚える）。
- **構成**: ふきだし（段階に合わせたひとこと）→ 質問のボタン（今日は、あと いくら使える？ など）→ 答えは、その場で計算（外には送らない）。

### 2-12. 設定とお問い合わせ  `13-app-settings.jpg` `14-contact.jpg`
- **設定**: たびまる（切り替え）・規約・プライバシー・お問い合わせ・版（このアプリについて）。**文字の大きさの行は、いったん外した**（v185。`--ts` の仕組みは残してある）。
- **お問い合わせ**: 種類（4つ）→ 内容 → 返信の希望 → 版と端末の送信（任意）→ ［送る］。

## 4. 画面を撮り直す

```
npm run build && (cd dist && python3 -m http.server 8799 &)
NODE_PATH=$(npm root -g) node <撮影スクリプト> docs/design
```
試用データ（3人・箱根＝旅行中・京都＝準備中で積立あり・熱海＝終了で精算あり）を、`localStorage['tabiwari.v1']` に入れて、390×844・`reducedMotion: 'reduce'` で撮る。
