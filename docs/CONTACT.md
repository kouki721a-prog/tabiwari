# お問い合わせ（v147）

アプリの設定 →「サポート」→「ご意見・お問い合わせ」から、誰でも（ログインなしで）送れます。内容は、サーバー（D1 の `contacts` 表）に保存され、運営者の公式LINEに、1通のお知らせが届きます。

## 送られるもの
内容（1000字まで）・種類（使い方・不具合・ご要望・その他）・返信の方法（なし／LINE／メール）。メールを選んだときはメールアドレス、LINEを選んだとき（ログイン中のみ）は LINE の表示名。「版と端末の種類を送る」がオンのときは、アプリの版と端末の種類（iPhone・Android・PC）。旅行のデータや名前は送らない。

## 迷惑な投稿の対策
1つの回線（IPアドレスの短いハッシュ）につき、1日3件まで。全体で、1日100件まで。内容は1000字まで。

## 運営者の設定（1回だけ）
1. Cloudflare の Workers → tabiwari → 設定 → 変数とシークレットで、**シークレット `ADMIN_TOKEN`**（12文字以上の合言葉。自分で決める。チャットには貼らない）を登録して、デプロイする。
2. アプリを、運営者のスマホで、LINEにログインした状態で、アドレスの最後に `#admin` を付けて開く（例: `https://（アプリのアドレス）/#admin`）。
3. 合言葉を入れて［運営者になる］。以降、このアカウントが運営者（`meta` の `admin_user`）。
4. 公式LINEを友だち追加していること（お知らせは、公式LINEから届く）。友だちでない間は、お知らせは届かないが、設定の「お問い合わせの一覧」には出る。

運営者を替えるときは、別のアカウントで、同じ手順をする（最後に登録した人が運営者）。合言葉を変えたいときは、`ADMIN_TOKEN` を入れ替える。

## 返信のしかた
アプリの中の返信画面は無い。一覧で、返信の方法を見て、メールなら、メールアドレスのリンクから。LINEなら、公式LINEのチャット（LINE Official Account Manager）から、表示名の人に、返す。

## 作り（開発者向け）
`worker/contact.js`（`POST /api/contact`、`GET /api/contact/list`、`POST /api/contact/delete`、`POST /api/admin/claim`）。運営者かどうかは `GET /api/me` の `user.admin`。400日たったものは、毎日の掃除で消える。アカウントを削除すると、そのアカウントから送ったものも消える。テスト: `test/contact.api.test.mjs`、`test/ui.e2e.mjs`。
