# ストア・紹介用の説明文

アプリの軸: **出発前の積立 → 旅行中の1日の目安 → 旅行後の通知つき精算**を、友人・カップルの国内旅行で、ひとつにつなぐ。割り勘の機能名より、この流れを先に伝える。

作らないもの: 旅程・しおり、アプリ内送金。決めていないこと: 外貨対応、有料プランの形と価格、アプリ名（同名の別サービス tabiwari.com がある）。

## 短い説明（72字。`manifest.json` の description も同じ）
旅行のお金の不安をなくす、友だち・カップル向けの国内旅行アプリ。出発前の積立、旅行中の1日の目安、旅行後の通知つき精算まで、ひとつにつなぎます。

## 長い説明
旅行のお金の不安を、出発前から旅行後まで、ひとつのアプリでなくします。

- **出発前**：ひとりずつの積立が、あといくらか分かります。
- **旅行中**：今日あといくら使えるかが、1日の目安で見えます。「夕食 2000円」のひとことや、レシートの写真で記録できます。
- **旅行後**：割り勘は自動で計算します。払う人には、通知でお知らせします。

友だちとは、リンクで共有します。無料で、登録もインストールも要りません。LINEでログインすると、通知とバックアップが使えます。
